# Project Roadmap

This document describes planned improvements and future development
for the project.

## v1.0 — Initial Release

- [x] Modern Android Auto / CarPlay infotainment
- [x] Raspberry Pi 5-based head unit
- [x] Original Volvo P2 RTI motorized display retained
- [x] OEM steering-wheel navigation controls
- [x] Volvo CAN bus integration
- [x] Volvo LIN bus integration
- [x] Arduino-based CAN watchdog and power supervisor
- [x] Intelligent ignition-based power control
- [x] Safe Raspberry Pi shutdown
- [x] Engine-cranking protection
- [x] PAL composite video output to the original RTI display
- [x] Integration with the factory Volvo audio system
- [x] OEM-style vehicle power and fuse-box integration
- [x] Custom 3D-printed mounting solutions
- [x] Stealth installation using original vehicle compartments
- [x] Open-source hardware and software documentation

## Future Development

- [ ] CAN-Based Low-Voltage Battery Protection;
      
      <i>Monitor vehicle battery voltage over CAN and implement intelligent power shutdown to prevent excessive battery discharge. </i>
      
- [ ] OEM Ambient Light-Based Display Control;
      
      <i>Integrate the factory ambient light sensor for automatic RTI display backlight adjustment.</i>
      
- [ ] OEM Temperature Sensor Integration;
      
      <i>Use the factory internal temperature sensor to monitor cabin/display-area temperature and implement thermal protection during high-temperature conditions.</i>

Note: Feature descriptions and implementation details will be expanded as development progresses.
